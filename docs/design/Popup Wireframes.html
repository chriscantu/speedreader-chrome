Tradeoffs

A. Live player
✓ instant gratification
✓ works without ever opening the modal
✗ popup closes if user clicks away — reading state has to persist
✗ small RSVP word may feel cramped
B. Article picker
✓ handles paste / URL / resume in one place
✓ useful without an article loaded
✗ more UI to learn
✗ history = more scope (storage, clearing, etc.)
C. Minimal launcher
✓ smallest, fastest to understand
✓ pairs well with the keyboard shortcut
✗ no in-popup reading
✗ no paste/URL path without going to options
